Herramientas

Importar productos

Cargá un archivo Excel para actualizar o agregar productos al catálogo. Columnas soportadas: CODIGO (obligatorio), CODIGO_BARRAS, DESCRIPCION, CATEGORIA, MARCA, PRECIO_MAYORISTA, ESTADO, PREVENTA (nombre de una preventa ya creada — si no matchea ninguna, el producto queda sin preventa).

Importar por código

Pegá una lista de códigos y elegí una preventa — el resto (descripción, categoría, marca, precio mayorista, código de barras y foto) se completa solo desde Manager2Max. Ideal para altas rápidas sin tipear nada a mano.

Descargar plantilla

Descargá una plantilla Excel vacía con los encabezados correctos para completar y luego importar.

Exportar catálogo completo

Descargá todos los productos actuales del catálogo en formato Excel. Útil como respaldo o para editar en masa.

Importar imágenes

Subí múltiples imágenes o un archivo ZIP para asignarlas masivamente. Nombrá cada imagen con el código del producto (ej: 33020.jpg).

Nota de pedido

Imprimí una hoja A4 con todos los productos disponibles del catálogo, agrupados por categoría, para usar como referencia de precios.
